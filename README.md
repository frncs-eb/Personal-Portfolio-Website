## Overview
For your exclusive use, this personal portfolio website acts as a dedicated digital repository and workspace to organize, reflect upon, and further develop your skills, experiences, and creative projects. It provides a structured platform to document your professional journey, meticulously catalog your key accomplishments, and serve as a dynamic space for ongoing self-assessment and growth. This personalized online environment is tailored solely for your benefit, offering a private and centralized hub for your career management and creative exploration.

## Features
- User account creation and authentication.
- Home tab: it comes with a welcome message and just for display only.
- Personal Information tab: This section allows users to upload a personal image and input a short description about themselves.
- Projects tab: users can input their recent projects, limited to four projects only
- Skills tab: makes the user able to showcase his/her skills, the input is limited to four skills
- Achievements tab: users can input their recent achievements, the input is limited to four achivements.
- Account tab: This section allows users to logout their account.

## Technologies Used
- Frontend: HTML, CSS, and JavaScript
- Development Environment: Visual Studio Code

This is a frontend-only application that runs directly in the browser without requiring a backend server.

## System Requirements
- Modern web browser (Chrome, Firefox, Safari, Edge)

## Setup Steps
1. Download the ZIP folder containing the website files
   - The ZIP includes HTML, CSS, JavaScript, and README.md files

2. Extract the ZIP folder to your desired location

3. Open the folder using Visual Studio Code or any other web development tool of your choice

4. Launch the website using one of these methods:
   - In VS Code: Install the "Live Server" or "Live Preview" extension and click "Go Live"
   - In other editors: Use their built-in web server functionality
   - Alternative: Simply open the index.html file directly in your web browser

## Usage

### Starting the Application
1. Open the extracted folder in VS Code or your preferred development tool
2. If using VS Code with Live Server:
   - Right-click on index.html and select "Open with Live Server"
   - Or click on the "Go Live" button in the status bar

### User Guide
1. **Getting Started**:
   - From the Login Page, create an account by clicking the sign up/register button
   - This will direct you to the sign-up page

2. **Registration/Login**:
   - Create an account on the sign-up page
   - Fill in the required information
   - Click "Sign Up" to create your account
   - You will be automatically directed to the Login Page

3. **Main Page Features**:
   - **Home Page**: In this page, this is just to welcome the user and for display only.
   - **Personal Information Page**: To upload an image, click the default image; select your file, and it will save automatically. For text, simply edit the default message, and it will also be saved automatically.
   - **Projects Tab**: To input a project, click the default text (project title & description) to edit it. Your changes will be saved automatically.
   - **Skills**: To input a skill, click the default text (skill name & description) to edit it. Your changes will be saved automatically.
   - **Achievements**: To input achievement, click the default text (achivement title & description) to edit it. Your changes will be saved automatically.
   - **Account**: To logout account, just click the logout button.
